# Plan — Issue #422: Collapse the three Go packages into one `arx_go` package

## Goal
Fold `parts_master_go` (`partsmaster`) + `test_records_go` (`testrecords`) + `arx_go` (`main`) into
**one module `arx/arx_go`, one `package main`**: one chi router built directly (drop PM's `NotFound`
fall-through), one embedded `templates/` + `static/` set, single `/static` (retire `/tr-static`).
`arxlib` stays as the shared lib module. Pure structural refactor — **no behavior change**.

Prereqs #419/#420/#423 are already merged, so the two packages' infra is now identical (the thing
that makes this a real collapse, not just a file move).

## Design (recommended)
**One `Handler`** (one db/cfg/store) + **two render paths**.
- Verified: the only `Handler` method-name collisions between the packages are the infra methods
  (`logSQL queryContext queryRowContext execContext csrfToken verifyCsrf session RequireAuth
  RequireCsrfOnPost CheckSchemaVersion CloseDB render renderPrint NotFound ServeLocalFile`). Every
  domain handler (`PartsList…FormsList…RecordDetail…`) is disjoint → attaches to one `Handler` with
  **zero renames**.
- Infra methods are now identical → keep PM's copy, delete TR's duplicates.
- **Rendering stays split** — the two `templateFuncs` share key names with *different* behavior
  (PM `formatDate`→`2006-01-02`, TR→`01/02/2006`; TR-only `pfBadge`/`applyFormat`). A merged funcmap
  would silently mis-format. So: `render`/`renderPrint` (PM, `templates/pm/*`, `pmTemplateFuncs`) and
  `renderTR`/`renderPrintTR` (TR, `templates/tr/*`, `trTemplateFuncs`). TR domain handlers switch
  `h.render`→`h.renderTR`. Suffix colliding free funcs (TR `formatDate`→`trFormatDate`). Unifying the
  visual shell is **#421**, out of scope.

## Steps
1. **Move** all `.go` + assets into `arx_go/`. Templates→`templates/{pm,tr}/`, static→`static/{pm,tr}/`
   (both have colliding `layout.html`/`index.html`/`app.css`). Rename file-level dupes: TR
   `files.go`→`trfiles.go`, `api.go`→`trapi.go`; merge TR `handlers.go` into the new
   `handlers.go`/`render.go`. Set package clauses → `main` (handlers) / `models`.
2. **Drop config/db shims** — import `arx/arxlib/config` (`arxbase`) + `arx/arxlib/db` directly. One
   `var AppVersion` in `main`; `main` calls `arxbase.Load(AppVersion)` once.
3. **Models** → one merged sub-package `arx/arx_go/models` (PM+TR types are disjoint).
4. **Delete** `parts_master_go/go.mod`, `test_records_go/go.mod`; `go.work` → `use ( ./arxlib ./arx_go )`.
   Delete the two old dirs. Rewrite all `arx/parts_master_go/...` + `arx/test_records_go/...` imports.
5. **One `buildRouter`** in `main.go`: single `/static/*` over merged tree (retire `/tr-static`);
   infra routes once (PM's `/settings /whats-new /api/browse-folder /local*`); all PM + TR domain
   routes on one mux under one `RequireAuth` group (disjoint — no shadowing); one `r.NotFound`.
   Delete `App` structs, `SetFallback`, `SetAfterSettingsSave`, TR `SetDBAndConfig` — one pool means
   settings-save reconnects `h.db` in place, no second app to notify.
6. **Templates repoint:** PM `/static/...`→`/static/pm/...`; TR `/tr-static/...`→`/static/tr/...`.
7. **Embed.go** (one): `//go:embed templates`, `static`, `RELEASE_NOTES.md` (keep one copy).
8. **build.bat:** tests → `go test ./...` (+ arxlib); `-ldflags` → single `-X arx/arx_go.AppVersion=%VERSION%`
   (drop the two old `-X` paths); keep `-H windowsgui` + CHANGELOG version parse.
9. **Tests:** merge `middleware_test.go`+`helpers_test.go` into `package main`, dedupe the shared
   `Test*`/`testHandler`/`sentinel`/`writeJSON`. Move `integration_test.go` (#416) → `package main`,
   fix its imports (`arxbase`, `arx/arxlib/db`); keep `//go:build integration` + ArxDev guard.
