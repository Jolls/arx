# #221 slice 5: RFQ → sqlc

Part of #221 / #190. Moves the last raw-SQL sites of the purchasing domain onto `internal/purchasing`.

## Coverage audit
- `RFQAddSupplier`: already free of raw SQL (`fetchPO`/`fetchPOItems`); nothing to do.
- `RFQCompareSave`: line-id read, per-line quote update, group total recompute (3 statements, one tx).
- `RFQConvert`: quote read, base-number-taken check, group `FOR UPDATE` lock, award claim, header
  `INSERT … SELECT`, line `INSERT … SELECT`, three history inserts, sibling list + decline.
- `rfq_bom.go`: supplier name (`buildRFQPlan`), default contact + `nextval` + PO/line/history/group
  inserts (`insertBOMRFQ`).
- Not too big for one PR; no split.

## Decisions
- Tx boundaries, statement order, the group lock, both `status='rfq'` guards and the
  sibling-changed-concurrently `continue` are unchanged (#191); tx statements run through
  `purchasing.New(tx)`.
- The rename to the bare base number is just the `number` param of a flat `INSERT … SELECT … RETURNING id`
  (`CopyPOForConversion`); the line copy is a second flat `INSERT … SELECT` (`CopyPOLines`). No
  alternative needed.
- New queries: `ListRFQLineIDs`, `SetRFQLineQuote`, `RecomputeRFQTotals`, `GetRFQQuote`
  (id/status/group/supplier by number), `LockRFQGroup`, `AwardRFQQuote` / `DeclineRFQQuote`
  (`:execrows`, guarded by `status='rfq'`), `CopyPOForConversion`, `CopyPOLines`,
  `CreatePOStatusEventNote`, `ListOpenRFQSiblings`.
- Reused: `GetPOState` for the base-number-taken check (found ⇒ taken), `GetSupplier` for both the
  supplier name and default contact, `NextPONumber`, `CreatePO`, `SetRFQGroup`, `CreatePOStatusEvent`,
  `CreatePOLine`.
- `RFQCompareSave` needs an int group id; a non-numeric group keeps failing with the
  "Error loading RFQ lines" error (today via a pgx encode error).
- `rfq_bom.go` and `pos.go` go into `convertedFiles`; `POTable`/`POLineTable`/`POHistoryTable`/
  `CompanyTable` helpers are deleted only if this leaves them with no non-test caller.

## Test plan
New `arx_go/rfq_integration_test.go` (`//go:build integration`), passing on the unchanged code first;
complements the existing RFQ tests in `integration_test.go` and the #191 races in
`tx_boundaries_integration_test.go`.
- Compare save: only the group's lines are written, an unposted line resets to 0, blank lead → NULL,
  total = lines + tax/shipping/misc, other groups untouched, unknown group, non-numeric group.
- Convert: header + line copy fidelity, draft/not_submitted/active, group and dates cleared, history
  notes/actors on new PO, winner and siblings, non-`rfq` sibling left alone, NULL-group quote,
  unknown number.
- BOM confirm: one quote per supplier, header/contact fields, zero costs (not NULL), own group,
  history row, only posted lines.

Verify: go build/vet (plus `-tags integration`), go test ./..., sqlc diff, gofmt -l on touched
